<h1 align="center">
🛡️ CyberShield - Password Strength Analyzer
</h1>

<p align="center">

Modern Cybersecurity Password Strength Analyzer Web Application built using Flask, SQLite, HTML, CSS, and JavaScript.

</p>

<br>

---

<h2>
🚀 Project Overview
</h2>

<br>

CyberShield is a cybersecurity-based web application that helps users:

<br>

✅ Analyze password strength  
✅ Detect weak passwords  
✅ Detect reused passwords  
✅ Store passwords securely using SHA-256 hashing  
✅ Experience a real cybersecurity dashboard UI  
✅ Learn password security concepts  

<br>

This project also includes:

<br>

✅ Login & Signup Authentication  
✅ SQLite Database Integration  
✅ Live Password Strength Meter  
✅ Matrix Hacker Animation  
✅ Floating Cybersecurity Icons  
✅ Neon Cyber Theme  
✅ Glassmorphism Hacker UI  
✅ Cybersecurity Dashboard  

<br>

<h2> ⚙️ Installation Guide </h2> <br> <h3> Step 1 — Clone Repository </h3> <br>
git clone https://github.com/narukalucky325-cyber/password-strength-analyzer.git
<br>
<h3> Step 2 — Open Project Folder </h3> <br>
cd CyberShield-Password-Analyzer
<br>
<h3> Step 3 — Install Flask </h3> <br>
pip install flask
<br>
<h3> Step 4 — Run Project </h3> <br>
python main.py
<br>
